# A little walkthrough. A great first impression.

## 90-second client demo

1. **Choose Admin in the role dropdown and sign in using the prefilled test fields.** Start with the acquisition chart, revenue, response time, funnel and agent leaderboard. The design is consistent across the workspace.
2. **Open Leads inbox → Unassigned.** Select leads, assign them to Ayesha, and show that ownership updates immediately. Search and filter the table.
3. **Open Ahmed Raza’s dedicated lead page (`#/lead/1048`).** Show the Facebook campaign/ad/form context, score, form answers and suggested next action. Explore the Activity timeline, Comments, Calls, Follow-ups and Notes tabs. Add a note; schedule a follow-up. Use the back button to return to the inbox.
4. **Start a demo call.** Watch the timer, end it, choose an outcome and log notes. It does not make a real call.
5. **Open Sales pipeline.** Drag a card to Interested or Negotiation. Counts and values change. Use the full lead page’s stage progress bar or Change status action on touch devices.
6. **Switch to Agent in the top bar.** The sidebar changes, only Ayesha’s leads are shown, and reassignment is disabled. Show daily targets and next-best conversation.
7. **Switch to Manager.** Show team-wide visibility without team-administration access. Admin has the Team & members screen.
8. **Finish with Dark mode and Ctrl/⌘+K.** A little premium detail makes the experience memorable.

## More to explore

- In Follow-ups, complete a task, view Completed, then open the monthly calendar.
- In Lead distribution, choose a strategy, configure it, then run it on unassigned leads.
- In Integrations, preview Facebook forms, connect a mock WhatsApp integration and see webhook health.
- In Reports, view agent performance and campaign ROI, then export current data as CSV.
- In Team, add a local member. No invitation is sent.
- Use a WhatsApp template, edit it, and copy it. Nothing is sent.

## Reset

Refresh `index.html` to restore the original demo data. Theme preference survives where local storage is enabled. None of these workflows connect to real accounts.
